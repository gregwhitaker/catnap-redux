# Historical requirement audit — November 16, 2026

This page preserves the earlier requirement audit and its source scope. For the current candidate status and remaining release steps, use the [release checklist](RELEASING.md). Passing this historical audit does not establish that later changes have been published or measured.

Audited the accepted first-release requirements on November 16, 2026. The accepted local implementation criteria are satisfied. The final build, compatibility matrix, independent publication consumers, streaming smoke suites, and claimed native-image checks pass; benchmarks and compatibility documentation accompany the candidate. The historical WebFlux drain timeout is preserved below with an unknown cause. Verification applies to the stated framework/runtime/operating-system combinations.

The November 19 [native verification supplement](https://github.com/gregwhitaker/catnap-redux/blob/main/docs/native/2026-11-19/README.md) covers the subsequent CATNAP dialect and catalog examples: 160 Quarkus and 152 Micronaut native tests pass on macOS AArch64, with no failures, errors, or skips. Quarkus now includes the existing configured-CATNAP HTTP suite through a native integration-test entrypoint. This supplement updates native correctness evidence; the November 16 audit and measurements below retain their original source scope.

## Historical timeout and verification limits

A subsequent [Java 17 launcher regression check](https://github.com/gregwhitaker/catnap-redux/blob/main/docs/verification/2026-11-16/java17-launch/README.md) passes the full build, compatibility matrix, and independent consumers after adding Java 25 daemon criteria. It also verifies provisioning from a Java 17 shell. This corrects build startup; library production sources and bytecode targets are unchanged.

The [WebFlux drain investigation](https://github.com/gregwhitaker/catnap-redux/blob/main/docs/benchmarks/2026-11-16/http/webflux-drain-audit/README.md) began with a timeout while draining a sparse NDJSON warmup window. The original failure recorded 356,373 expected records but no delivered count. Earlier status wording described a count mismatch; the available evidence establishes a missed 15-second drain deadline, without distinguishing delayed delivery, a stall, accounting behavior, or missing/duplicate records. Its cause remains unknown.

Follow-up runs pass exact global and per-connection count/byte assertions: repeated boundaries and reconnects, paused readers with backlogs exceeding 200,000 records, and synchronous sources. A replay compiled from the original archived runner, source, reader, and servers passes all 24 MVC/WebFlux measurement cases, with only failure-reporting instrumentation added. No WebFlux production fix is claimed, and a passing replay does not prove the timeout cannot recur. The original failed attempt and all diagnostics remain archived.

The local release verification criteria are satisfied by the current passing test, publication, native, and measurement evidence. No required case, exact-count assertion, deadline, or retention threshold was removed or relaxed. The historical timeout is retained as an unexplained observation rather than a claimed fixed defect or confirmed data-loss finding. This assessment completes local implementation verification; it does not certify every deployment or authorize public publication.

Micronaut's direct-memory failure has a repeatable source/cleanup matrix and a production mitigation verified on all six Catnap stream modes. The [updated performance run](https://github.com/gregwhitaker/catnap-redux/blob/main/docs/benchmarks/2026-11-16/http/attempt-4-micronaut/summary.json) passes all 12 cases and accompanies the full-build and native-image reruns; the throughput cost is explicitly recorded.

The subsequent [hosted snapshot verification](PUBLICATION.md#hosted-snapshot-verification) records GitHub Packages upload and fresh remote consumption of `3.0.0-SNAPSHOT` on Ubuntu 24.04. Release signing with real credentials, additional framework versions, and additional native-image operating systems remain outside the recorded evidence. The dated local records above preserve their original verification scope and include the historical serialization probes present in those snapshots. Current examples exercise serialization visibility and generic type preservation through the production integrations; see the [examples guide](examples/README.md).

At the recorded audit baseline, legacy value predicates/JSONP, an SSE replay store, and incremental projection of one unbounded JSON document were outside the accepted scope. The current source defaults to the CATNAP dialect with its [RSQL subset](QUERY_SPECIFICATION.md#catnap-array-predicates). The November 16 benchmark/native/release evidence predates that addition; the November 19 native supplement verifies predicate behavior in Quarkus and Micronaut. Predicate performance and publication of the newer source require separate evidence. No hard real-time guarantee is claimed.
