SHORT DESCRIPTION
Catnap is a JVM JSON projection library for selecting fields from JSON.
A focused core and separate integrations help developers keep responses
clear and intentional.

LONG DESCRIPTION
Catnap is a JVM JSON projection library that selects fields from materialized
JSON using explicit query expressions. Its core compiles selections into
reusable plans and evaluates them through a JSON-tree adapter. Separate
bindings support native JSON representations, keeping projection focused on
the data already produced by an application's serializer. Use Catnap to
express which fields belong in a response while preserving selected values.

EXAMPLE CAPTION

JSON omits the other object members and preserves the selected values.

WRITING RULES
Use sentence case. Prefer select, project, query, field, response and JSON.
Keep cat and sleep metaphors occasional and visual. Do not use them to imply
runtime laziness, speed, reliability or automatic performance improvements.
Avoid unsupported superlatives and promises such as fastest, zero overhead,
production-ready everywhere, or support for every JVM framework.
Explain the scope of a compatibility or performance claim and link evidence.

PRODUCT ACCURACY
Projection selects existing JSON fields; it does not fetch missing data.
The core is separate from HTTP transport integrations.
Do not imply that projection is an authorization mechanism.
For this project snapshot, framework HTTP and streaming integration remain
work in progress. Check the current README before release announcements.
