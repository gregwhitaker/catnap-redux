# Verification records

Dated results, environments, and source snapshots for Catnap verification:

- [Benchmarks](benchmarks/): CPU, allocation, throughput, latency, and retained-memory measurements.
- [Native images](native/): Quarkus and Micronaut build logs, test reports, and executable hashes.
- [Release verification](verification/): JVM builds, compatibility checks, and publication-consumer results.

Each report applies to its recorded source and environment. New verification belongs in a new dated record; retain earlier results and diagnostics.
