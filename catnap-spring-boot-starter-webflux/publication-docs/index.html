Catnap Spring WebFlux starter

This dependency-only artifact brings in the WebFlux adapter and Boot auto-configuration. It has no Java API of its own.

Configure GitHub Packages before adding this dependency. See the included installation guide.

implementation(platform("com.github.gregwhitaker:catnap-bom:3.0.0"))
implementation("com.github.gregwhitaker:catnap-spring-boot-starter-webflux")

Use ?fields=name,price(amount) to select response fields. Configure catnap.dialect=LINKEDIN to use name,price:(amount).

The implementation API documentation is in the catnap-spring-webflux and catnap-spring-boot-autoconfigure documentation artifacts.

Included integration guide: configuration, finite JSON, NDJSON, SSE, bounds, and failure behavior.
